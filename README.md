# Nexo - Sitio Web

Sitio web oficial de Nexo desarrollado en HTML5, CSS3 y JavaScript moderno.

## 📁 Estructura del Proyecto

```text
Nexo/
├── index.html        # Página principal
├── estilos.css       # Hoja de estilos con soporte Dark/Light mode
├── script.js         # Lógica interactiva y componentes dinámicos
└── img/              # Recursos visuales e imágenes
    ├── logo.png      # Logo de la marca
    └── foto.jpg      # Imagen principal del showcase
```

## 🚀 Uso local

Para visualizar el sitio, abre el archivo `index.html` en cualquier navegador web o utiliza una extensión de servidor local como *Live Server* en VS Code.
